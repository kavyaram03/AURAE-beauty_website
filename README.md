# AURAÉ — Beauty E-Commerce Website

AURAÉ is a modern and responsive beauty e-commerce website designed to provide a simple and elegant shopping experience for beauty enthusiasts. The website allows users to explore beauty products across skincare, makeup, and fragrance categories with interactive search and filtering features.

## 🌸 Features

* 🏠 **Home Page** — Introduction to AURAÉ with featured products and promotional sections.
* 🛍️ **Collections Page** — Browse beauty products across different categories.
* 🔍 **Search Functionality** — Search for products by name.
* 🏷️ **Category Filtering** — Filter products by Skincare, Makeup, and Fragrance.
* ❤️ **Like Feature** — Like or unlike products using the heart button.
* 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
* 📩 **Contact Page** — Provides contact information and a simple contact form.
* ☰ **Responsive Navigation** — Mobile-friendly navigation menu.

## 🛠️ Technologies Used

* **HTML5** — Structure and content
* **CSS3** — Styling, layouts, animations, and responsive design
* **JavaScript** — Search, filtering, navigation, slider, and interactive features
* **Font Awesome** — Icons
